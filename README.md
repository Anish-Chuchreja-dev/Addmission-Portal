# 🎓 Admission Portal — HTML Project

A simple **Admission Portal form** created using HTML as part of my web development learning journey. This project demonstrates the use of HTML forms, input fields, dropdown menus, file uploads, and other basic HTML elements.

## 📌 About the Project

The Admission Portal is a basic student information form designed to collect essential details from applicants. It is a beginner-friendly project built to practice HTML form elements and understand how user input works on a webpage.

## ✨ Features

- 👤 First name and last name input fields
- 🎂 Age input field
- 🎓 Course selection dropdown
- 📧 Email input field
- 📁 File upload option
- 🎨 Color picker
- 📊 Progress slider (0–100)
- ✅ Submit and Reset buttons
- 🔘 Additional button element

## 🛠️ Technologies Used

- **HTML5** — Structure and form elements
- **CSS** — No custom CSS styling implemented yet
